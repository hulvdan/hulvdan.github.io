# hulvdan.github.io — agent context

Personal game-dev portfolio of Hulvdan + a few articles. Static site generated by a Python
script, served by GitHub Pages from `docs/`. UI in Russian, Persona 5-ish game style.

## Stack

- Python 3.11+, `uv`. One script: `main.py` (typer CLI)
- markdown2 for content, Jinja2 for pages, Pillow + pypng for images, cogapp for generated md blocks
- Plain CSS / JS, no bundler. Gallery: PhotoSwipe 5 (ES module from jsDelivr, loaded on first click)
- Brand icons: Simple Icons from jsDelivr via CSS masks
- Dev server: livereload (`docs/` as root, rebuild on source change)
- Hooks: prek (`.pre-commit-config.yaml`)

## Layout

```
pages/index.md        portfolio page (`!LAYOUT portfolio`)
pages/habits.md       article
pages/useful/*.md     articles; `NN__slug.md` -> docs/useful/NN.html, `_` prefix = draft
templates/base.html   shared <head>, background
templates/portfolio.html + _macros.html   portfolio page (hero, sections, cards)
templates/page.html   articles
site.css / site.js    all styles / behaviour, copied to docs/ under a content hash
pygments.css          code highlighting for articles
docs/                 build output (GitHub Pages root). Do not hand-edit *.html / hashed css+js
docs/assets/          images; `th__<stem>.jpg` thumbnails are generated by the build
```

## Commands

```
uv run python main.py build       # generate docs/
uv run python main.py cog         # refresh [[[cog]]] blocks in md
uv run python main.py interlace F # make images progressive (hook does it)
uv run pytest -q
uv run prek install               # once after clone
```

## Portfolio markdown (`pages/index.md`)

Parsed by `parse_portfolio` in `main.py` into dataclasses (`Hero`, `Section`, `Card`, `Link`),
rendered by `templates/portfolio.html`.

- Hero (before the first `##`): `# Name` (ransom-letter title), `!TAGLINE`, intro text, `!CONTACT <github|itch|mail> <url>`
- `## Title` = section. Its kind is inferred:
  - has `### Card` -> cards
  - `!IMAGES a.gif b.jpg` -> image grid
  - `- [text](url)` lines -> numbered link list
  - else plain markdown
- Card directives: `!STICKER`, `!GENRE`, `!DATE`, `!COVER` (default: first image), `!IMAGES a.png youtube:<id>`,
  `!TAGS a, b` (links from `TAG_URLS`), `!VIDEO <label> <youtube id>`, `!LINK <label> <url>` (icon from `LINK_ICONS`), `- note`
- `#{ ... }#` is stripped (hidden links), `<!-- -->` ignored, ` -> ` -> ➜, ` - ` -> —
- Section / card ids are slugs of titles (Cyrillic kept) and serve as anchors

Article markdown uses old directives handled by `process_line`: `!SPOILER_START/END`, `!FLEX_*`,
`!IMAGES`, `!YOUTUBE_<id>`, `!PAGE`.

## Front-end notes

- Palette lives in `:root` of `site.css` (`--accent` #fabf61, `--white` #f5eeb0 cream, `--panel`)
- `.reveal` elements slide in on scroll (IntersectionObserver); they own `transform`,
  so other effects on them use `rotate` / `scale`
- Phones: no sideways slide-in, `overflow-x: clip` (off-screen transforms widened the page on iOS)
- Gallery: one PhotoSwipe gallery per card / image grid / article. Items are `[data-full]`
  (with `data-w` / `data-h` from the build) and `[data-video]`; only the current video slide gets a `src`
- No ◀ ▶ characters: iOS shows them as emoji. Triangles are drawn (`.tri`, clip-path)
- Anchors re-jump after fonts / images load (`site.js`)
